cloudos 1.0 beta

минимальный linux, который ты собираешь сам

cloudos это независимая система на базе lfs: glibc, openrc и ванильное ядро. после установки в ней только консоль и root, всё остальное ты добавляешь сам из исходников.

из чего состоит

собрана с нуля

база lfs 12.4 с glibc. никаких готовых бинарников чужих дистрибутивов.

openrc

простая система инициализации и служб, без systemd.

ванильное ядро

ты сам настраиваешь ядро через menuconfig под своё железо.

limine

быстрый загрузчик для uefi и bios, настраивается одним файлом.

ext4 и btrfs

на выбор, с поддержкой подтомов и снимков.

cloudpkg

пакеты только из исходников, рецепты основаны на gentoo.

установка в восемь шагов

установка ручная, как в gentoo, без мастеров. каждый шаг подробно описан в справочнике.

  1. 1подготовкаlive iso, сеть, время
  2. 2дискразметка и файловые системы
  3. 3stage 3скачать и распаковать
  4. 4chrootвход в новую систему
  5. 5ядроmenuconfig и сборка
  6. 6загрузчикinitramfs, fstab, limine
  7. 7завершениепароль и службы
  8. 8первая загрузкапользователь, имя, сеть, swap

как это выглядит

терминал
$ lsblk -f
$ mount /dev/sda2 /mnt/cloudos
$ tar xpvf cloudos-stage3-1.0-x86_64.tar.xz --xattrs-include='*.*' --numeric-owner -C /mnt/cloudos
$ chroot /mnt/cloudos /bin/bash
$ cloudpkg install limine

что внутри

  • gcc, glibc, binutils, python
  • openrc, udev, dhcpcd
  • opendoas вместо sudo
  • curl, git, nano
  • dracut, btrfs-progs, dosfstools

чего нет

  • графики и окружений
  • man-страниц, есть справочник
  • ssh-сервера и фаервола
  • arm, только x86_64
  • установщика с мастерами
