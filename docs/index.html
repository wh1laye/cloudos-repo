безопасность по умолчанию


защита включена сразу после установки, а не спрятана в главе «потом настроишь».


фаервол с первой загрузки
nftables: входящие закрыты, исходящие открыты. управление через cloudos-firewall.
подписанные релизы
sha256 всех файлов и подпись minisign для stage 3 и iso, публичный ключ лежит на сайте.
attestation в github actions
происхождение сборки подтверждается в самом github, а не только словами.
sshd выключен
openssh стоит, но не запущен. root по ssh закрыт, включается двумя командами.






cloudpkg


обёртка над portage: пакеты собираются из исходников, на btrfs перед обновлением делается снимок.




cloudpkg
$doas cloudpkg sync$doas cloudpkg search htop$doas cloudpkg install -a htop$doas cloudpkg upgrade$doas cloudpkg rollback


снимки btrfs
upgrade сначала делает снимок корня, rollback загружается из него.
проверка при установке
исходники cloudpkg проверяются подписью minisign, без неё установка отменяется.
доктор
cloudpkg doctor проверяет настройку, cloudpkg fix чинит окружение portage.

частые вопросы


это отдельный дистрибутив или сборка чужого?
собственная система: база собрана по lfs с glibc, свой установщик, свой загрузочный образ и свои сборочные скрипты. рецепты пакетов в cloudpkg основаны на gentoo.
на каком железе работает?
только x86_64, uefi и старый bios. на странице «железо» собрано, на чём проверено.
есть ли графика?
нет, после установки только консоль. всё остальное ты добавляешь сам через cloudpkg.
как проверить, что iso не подменён?
сверь sha256 и, если в релизе есть файл .minisig, подпись minisign ключом с сайта. подробности на странице «проверка файлов».
безопасно ли в live пароль cloudos?
пароль cloudos известен всем и нужен только для live, ssh в live закрыт. в установленной системе такого пароля нет.
