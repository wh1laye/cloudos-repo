Что это

CloudOS — это самостоятельная Linux-система. База собирается по мотивам книги Linux From Scratch с нуля, на glibc. Пакеты собираются из исходников нашим собственным пакетным менеджером cloudpkg, без использования каких-либо сторонних движков.

После установки у тебя чистая консоль и обычный пользователь с doas. Всё остальное ты добавляешь сам, так как хочешь.

🚧 Проект живёт в моём темпе. Сроков выхода версий нет. Готовится live iso 2.4: установка одной командой, без stage 3.

Что внутри

🏗️ База

LFS с нуля, библиотека glibc.

🚀 Инициализация

openrc.

🥾 Загрузчик

limine (ставит установщик).

📦 Загрузка ядра

Без initramfs, драйверы дисков и ФС встроены в ядро.

💽 Файловые системы

ext4 и btrfs.

🖥️ Железо

Только x86_64, UEFI и старый BIOS.

🌐 Сеть

dhcpcd, wifi через iwd.

📜 Логи

syslog-ng.

🔐 Права

doas вместо sudo.

🔑 Удалённый доступ

openssh, rsync, wget. SSH выключен по умолчанию.

🛡️ Фаервол

nftables через cloudos-firewall, проверка cloudos-audit.

🐚 Оболочка

bash.

⚙️ Компиляторы

gcc и clang, на выбор.

Чего нет специально: графики и окружений рабочего стола, графического установщика (есть консольный cloudos-install).

Как поставить

  1. 💿 Скачай live iso со страницы релизов и проверь сумму.
  2. 🔌 Запиши на флешку и загрузись. Вход в live: cloudos / cloudos.
  3. ⚡ Выполни doas cloudos-install: режим auto стирает выбранный диск целиком, режим manual трогает только указанные разделы root и boot.
  4. 🔁 reboot.

Подробно всё написано в справочнике.

Пакеты

Программы ставятся только из исходников через наш пакетный менеджер cloudpkg:

cloudpkg sync      # обновить дерево рецептов
cloudpkg install   # поставить пакет
cloudpkg remove    # удалить пакет
cloudpkg upgrade   # обновить то, что устарело
cloudpkg clean     # почистить кэш и сироты

Это полностью автономный движок на C. Никаких сторонних пакетных менеджеров, только свои рецепты из репозитория cloudpkg-recipes.

Защита в live iso 2.4

  • 🔏 cloudpkg update и install.sh проверяют подпись minisign.
  • 🧱 cloudos-uki: подписанный unified kernel image.
  • 🔑 cloudos-tpm2: разблокировка luks через TPM2.
  • 🛡️ AppArmor в ядре, профили в режиме complain.
  • 📋 cloudos-audit --cis: проверки по мотивам CIS benchmark.
