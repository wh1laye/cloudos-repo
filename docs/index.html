из чего состоит

быстрая установка

система распаковывается прямо из iso, без скачивания и компиляции.

усиленная база

kspp-опции ядра, подпись модулей, nftables с drop, root только через doas.

ядро без initramfs

драйверы дисков и файловые системы встроены, загрузка короче.

openrc

простая система служб без systemd, службы стартуют параллельно.

limine

быстрый загрузчик с одним файлом конфига, для uefi и bios.

cloudpkg

пакеты из исходников, рецепты основаны на gentoo.

установка в три шага

одной командой или вручную по справочнику.

  1. 1live isoзапиши на флешку и загрузись
  2. 2cloudos-installдиск, пароли, всё остальное само
  3. 3rebootвход, сеть, пакеты

как это выглядит

терминал
$ doas cloudos-install
$ reboot
$ doas cloudpkg install nano

что внутри

  • gcc, glibc, binutils, python
  • openrc, udev, dhcpcd, iwd
  • opendoas вместо sudo
  • curl, git, nano, wget, rsync
  • nftables, gnupg, man-db
  • cloudpkg для пакетов

чего пока нет

  • выбор рабочего стола и графики
  • arm, только x86_64
