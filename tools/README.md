# Инструменты сборки CloudOS
Скрипты для сборки базы (stage 3), live iso и ядра cloudk, а также тесты.
## Сборка stage 3
build-stage3.sh запускает chroot и stage3/build-inside.sh, который ставит пакеты через cloudpkg по списку cloudos-packages.list.
