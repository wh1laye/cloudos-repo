# безопасность

нашёл уязвимость в cloudos, cloudpkg, сборке или форуме: не пиши об этом в публичный issue.

напиши через вкладку security репозитория (report a vulnerability). в сообщении укажи версию, шаги воспроизведения и что можно сделать с уязвимостью.

что проверяется в сборке: sha256 всех исходников, sha256 stage 3 и iso, attestation происхождения в github actions.

live-образ cloudos содержит известный пароль (пользователь cloudos, пароль cloudos). это сделано намеренно, только для live, ssh для него закрыт. в stage 3 и в установленной системе такого пароля нет.
